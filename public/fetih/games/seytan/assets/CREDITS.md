# Şeytan Avı: credits and licences

All graphics (sky, mosques, sea, courtyard, props, the devil, the throwers, rocks, catapult,
particles) are built procedurally with three.js in `js/world3d.js`, `js/devil3d.js`,
`js/thrower3d.js`, `js/vfx3d.js` and `js/noise.js` (original work, CC0 like the project's own assets). The devil's laugh is
synthesised with Web Audio in `js/main.js`.
